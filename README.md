# Taskflow — список задач

Небольшое адаптивное приложение для управления повседневными задачами. Работает на чистых HTML, CSS и JavaScript, не требует установки зависимостей или сборки.

## Возможности

- Добавление, выполнение и удаление задач.
- Приоритеты: низкий, средний и высокий; приоритет можно менять после создания. Выбранный приоритет сохраняется и не сбрасывается после добавления задачи.
- Фильтры «Все», «Активные» и «Выполненные».
- Сортировка задач: сначала новые, по приоритету (высокий → низкий) или по алфавиту в обе стороны — А → Я и Я → А (с учётом выбранного языка).
- Счётчик оставшихся задач и очистка выполненных.
- Русский и английский интерфейсы.
- Светлая и тёмная темы с учётом системных настроек при первом запуске.
- Сохранение задач и настроек в `localStorage`.

## Структура проекта

- `index.html` — разметка и шаблон задачи.
- `style.css` — темы, адаптивная вёрстка.
- `script.js` — состояние, i18n, сортировка, `localStorage`.
- `README.md` — этот файл.

## Как запустить локально

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Дважды щёлкните по файлу `index.html` — приложение откроется в браузере. Если файл открывается в редакторе, выберите «Открыть с помощью → браузер».

Для локального запуска сервер и установка пакетов не нужны.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Добавьте файлы проекта (`index.html`, `style.css`, `script.js`, `README.md`, `.gitignore`) и отправьте их в ветку `main`.
3. Откройте репозиторий на GitHub и перейдите в **Settings**.
4. В боковом меню выберите **Pages**.
5. В разделе **Build and deployment** выберите источник **Deploy from a branch**.
6. Выберите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
7. Дождитесь публикации и откройте адрес сайта, который появится в разделе Pages.

## Хранение данных

Задачи, выбранный фильтр, сортировка, последний выбранный приоритет, тема и язык хранятся локально в браузере в `localStorage`. Данные не синхронизируются между устройствами и браузерами.

## Возможные улучшения

- Синхронизация между вкладками через событие `storage`.
- Редактирование текста задачи по двойному клику.
- Экспорт и импорт задач в формате JSON.
- Клавиатурные сокращения (например, `N` — новая задача, `/` — поиск).
- Сортировка выполненных задач в конец списка.
- Подсветка просроченных задач (после добавления дедлайнов).
- PWA-манифест, чтобы сайт ставился на телефон.

## Использование ИИ

Проект создан с помощью AI-инструментов: ChatGPT использовался для генерации каркаса и текстов интерфейса, Cursor — для правок и отладки. Ручная работа: проверка всех сценариев (создание, выполнение, удаление, сохранение после перезагрузки, смена языка и темы), исправление найденных багов, деплой на GitHub Pages.
